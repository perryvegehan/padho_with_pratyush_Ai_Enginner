# Two Sum

Given an array of `n` integers and a `target`, print the indices (0-based, smaller first) of the
two numbers that add up to `target`. Exactly one answer exists.

Input: first line `n`, second line `n` integers, third line `target`.
Output: two integers separated by a space.

Example: `2 7 11 15`, target `9` -> `0 1`
